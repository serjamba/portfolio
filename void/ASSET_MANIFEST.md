# VOID — происхождение материалов

Ни одна работа не скопирована из чужого портфолио. Коммерческие клиенты и результаты не выдумываются.

| Файлы | Автор/источник | Права и изменения |
|---|---|---|
| assets/logos/void.svg, void-light.svg, favicon.svg | Создано для концепта VOID; tools/create-svg.cjs | Собственные векторные пути, не сторонний логотип |
| assets/logos/lumen-sign.svg; assets/images/lumen-*.svg | Создано для концепта VOID | Три одинаковых дуговых сегмента, единая геометрия в src/components.js и генераторе |
| assets/images/rift-*.svg | Создано для концепта VOID | Авторские типографические композиции, без сторонних афиш |
| assets/images/fold-print.svg, fold-card.svg | Создано для концепта VOID | Авторская графическая система, не производственная спецификация |
| assets/images/fold-*.webp | Собственный WebGL-рендер tools/render-assets.cjs | Рендер одной модели src/three/fold-model.js; cover/flat/стадии/ракурсы |
| src/three/fold-model.js, печатные CanvasTexture | Создано для концепта VOID | Собственная панельная иерархия и детерминированная бумажная фактура; не внешний GLB |
| assets/images/studio.svg | Создано для концепта VOID | Редакционная раскладка собственных носителей; не фотография реального офиса |
| assets/fonts/InterVariable.woff2 | Rasmus Andersson, Inter, https://rsms.me/inter/ | SIL OFL 1.1; лицензия assets/fonts/OFL.txt. Локальная независимая копия лицензированного файла из доступного проекта |
| assets/vendor/three/three.module.js | Three.js contributors, r170, https://github.com/mrdoob/three.js/tree/r170 | MIT; assets/vendor/three/LICENSE.txt, немодифицированная локальная копия |

SVG использует системный Arial для текста на носителях; файл шрифта Arial не распространяется. UI и CanvasTexture используют локальный Inter. Все изображения имеют собственный исходник; растровая генерация AI не применялась, поскольку логотипы, графика упаковки и типографика требуют редактируемого векторного/кодового оригинала.

LUMEN / FOLD / RIFT — самостоятельные демонстрационные названия. Доступность обозначений и возможность коммерческого использования брендов не проверены. Это не утверждение о регистрации торговых марок.
